# Smart Employee Management System

A web-based Employee Management System built using **Python (Flask)** and **MySQL**.

## Features
- Admin login (session-based)
- Add, view, edit, delete employee records
- Mark, edit, delete employee attendance
- View departments
- Dashboard with employee/department/attendance counts

## Tech Stack
Python, Flask, MySQL, HTML, Bootstrap

## Setup
1. Clone the repo
2. Install dependencies: `pip install flask mysql-connector-python python-dotenv`
3. Create a `.env` file with your MySQL credentials (host, user, password, database)
4. Set up the MySQL database (`admin`, `employee`, `attendance`, `department` tables)
5. Run: `python app.py`
6. Open `http://127.0.0.1:5000`
